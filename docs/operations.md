# 操作、审计与故障处理

## 数据版本和留出隔离

完整清单是 `standard_text.jsonl` 与 `complex_file.jsonl` 的并集，共 16,000 个唯一样本。`split` 为 train/dev/holdout/gate，独立且互斥。文档 ID、父文档 ID 跨 split 冲突、样本 ID 重复、内容重复、金标错误边界/文本、交叉重叠及文件摘要不一致都会阻止评测。嵌套允许，重复金标禁止。

接入真实数据时，按 `schema.Sample` 准备两个 JSONL 与受控相对文件路径，运行 `validate --register-version NEW_VERSION` 生成新 manifest。不得把未验证的模型输出直接当金标。留出集的真实文件 ACL、对象存储只读和访问授权由组织环境落实；本地 CLI 的 `--allow-holdout` 只提供显式使用及审计，不能冒充安全隔离系统。

合成图片的像素还取决于字体。跨机器追求相同文件摘要时，使用交付的冻结文件，或通过 `PII_TEST_FONT` 指定相同字体文件；Windows微软雅黑与Linux文泉驿生成的图片不会有相同字节。字体变化会改变数据版本摘要，不允许静默与原数据版本混比。

## 门禁与基线

L1 输出 PASS/BLOCK，遇到软阈值保守阻断；L2 输出 PASS/WARN/BLOCK；L3 需要合规签字记录。硬失败退出码 2，数据/配置等执行错误退出码 1；禁止用忽略退出码绕过 CI。报告包含失败指标、样本、阶段、trace 和最小复现命令。门禁策略指纹变化会阻断与旧策略基线的比较。`conf/eval.yaml` 的阈值/权重仍是待真实业务确认的示例，不是自动取得了合规批准。

候选不能与自己建立的基线证明质量“无退化”。工程 `verify` 中的自对照只用于判断故障注入是否被正确拦截；生产 CI 使用独立冻结基线。数据/规则变化必须重新基准化；模型比较用相同样本的配对区间，不把无显著差异说成更优。

`approve-change --kind threshold|rule|data --before OLD.json --after NEW.json --approval APPROVAL.json --out AUDIT.json` 保存旧/新摘要及独立审批人、理由、生效版本。它记录组织已有的审批证据，不自动代替人工签字或认证审批人身份。

## 反馈回流

`review-queue` 把错误、低置信、灰区样本加入 SQLite 文件复核账本，不启动服务；相同样本/预测/原因幂等入队。`feedback record` 记录 accepted_as_is、accepted_with_edit、rejected 及字符差异。两名不同 reviewer 的最新结论必须一致且均接受，才能 promote/export。

`apply-feedback` 校验双人记录，复制受影响数据到全新目录，将经过复核的 dev/online 派生样本纳入 gate，并重新生成 manifest；源集、训练集、留出集不会被改写。当前 apply 入口针对已有样本 ID；全新线上样本先以统一 schema 加入独立待评估数据版本，再完成同样复核流程。跨页父文档只迁移一部分会被泄漏校验拦截。

`quality --data` 生成按轨道/版式分层的 20% 双盲、5% 专家、10% Teacher 检查任务计划；尚未执行就不能称为质检通过。`quality --left A.json --right B.json` 要求相同候选 ID/顺序，计算包含 NOT_PII 的候选级 Cohen Kappa，避免仅用两个正例实体集合伪算 Kappa。单一标签、机会一致率为 1 时 Kappa 未定义，不强行返回 1。

## 漂移监控

`drift` 从时间戳快照离线生成告警：每日足额人工抽检的高风险召回连续3日下降>2pt、误删>基线1.5倍、P95>1.3倍且持续1小时、单页成本>预算1.2倍、Teacher占比超阈值、解析/导出失败>0.5%。无人工金标时不计算线上召回；单个瞬时高延迟不算持续1小时。本项目不自动建立外部定时任务，组织可用既有调度系统调用 CLI。

`gate-health REPORT1 REPORT2 REPORT3` 识别连续满分类别，输出轮换建议；不会自动替换金标或下调阈值。

## 常见故障

| 现象 | 应检查 | 处理 |
|---|---|---|
| 模型/OCR 429、超时 | 地址、凭据、QPS、timeout、interval | 有界指数退避；仍失败则保留错误，不缓存成功 |
| 断点提示版本不一致 | 数据/规则/模型/源代码/配置摘要 | 新建输出目录，禁止混合历史断点 |
| 源文件摘要不一致 | 是否原地编辑/替换了文件 | 复核后创建新数据版本 |
| 扫描件无文本 | OCR mode、既有引擎、bbox单位 | 显式接入OCR；不得用空结果代表成功 |
| 高风险不足50/类别 | 门禁分层/长尾覆盖 | 补齐独立复核数据，不用均值掩盖 |
| PDF/DOCX回填失败 | 字形坐标、域、超链接、异常文件 | 用失败样本复现，必要时接入专用SUT |
| Langfuse无结果 | enabled、服务兼容、凭据、flush、主账本摘要 | 明确失败后恢复连接/续跑，不能声称云端已接通 |

Windows 的依赖下载若遇到网络限制，使用组织批准的代理/镜像。不要关闭 TLS 校验、修改系统网络策略或安装全局数据库来“跑通测试”。
